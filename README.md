# ZumActions — Duo Emotes

Mod de Fabric para Minecraft 1.21.1 que agrega interacciones sincronizadas entre dos jugadores (abrazos, besos, llevar de la mano, llevar de caballito, chócala, pat pat, y más), extensible mediante datapacks.

## Requisitos

- JDK 21+
- IntelliJ IDEA (Community Edition)

## Desarrollo

- `./gradlew runClient` — corre un cliente de desarrollo con el mod cargado.
- `./gradlew build` — genera el jar en `build/libs/`.
